# Structured Output Schema

Developer-experience review output should include:

- `executiveSummary`: contributor workflow assessment and main friction points.
- `findings`: setup, command, configuration, error, test, documentation, or local workflow issues.
- `onboardingImpact`: how each issue affects new or recurring contributors.
- `recommendations`: precise docs, command, error-message, or workflow improvements.

Prioritize repeatable workflow friction over cosmetic polish.

# Structured Output Schema

Return a coding-test evaluation with:

- `candidateSummary`: overall assessment, level signal, and production readiness.
- `scores`: correctness, code quality, architecture, performance, testing, and total score.
- `rubricFindings`: evidence mapped to each rubric category.
- `strengths`: concrete positive signals.
- `risks`: blockers, missing requirements, and concerns.
- `hiringOrAcceptanceRecommendation`: clear decision with rationale.

Focus on evidence from the submitted code and assignment context.

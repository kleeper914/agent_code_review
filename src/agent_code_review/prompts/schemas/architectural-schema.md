# Structured Output Schema

Architectural review output should include:

- `executiveSummary`: architecture assessment, major strengths, and critical risks.
- `findings`: design concerns with `id`, `severity`, `category`, `location`, `impact`, `recommendation`, `effort`, and `confidence`.
- `architectureThemes`: cross-file patterns, dependencies, coupling, and modularity observations.
- `recommendations`: near-term and strategic improvements.

Prefer concrete evidence over abstract architecture commentary.

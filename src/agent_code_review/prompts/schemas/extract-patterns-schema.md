# Structured Output Schema

Return a pattern library with:

- `patterns`: reusable patterns with `name`, `category`, `description`, `locations`, `whyItWorks`, and `reuseGuidance`.
- `antiPatterns`: risky repeated patterns with evidence and avoidance guidance.
- `domainConventions`: project-specific naming, layering, testing, or integration conventions.
- `candidateTemplates`: abstractions or examples that could be reused safely.
- `confidence`: confidence and evidence quality for each pattern.

Separate proven reusable patterns from one-off implementation details.

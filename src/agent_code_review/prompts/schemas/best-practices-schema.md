# Structured Output Schema

Best-practices review output should include:

- `executiveSummary`: overall adherence to idiomatic and maintainable patterns.
- `findings`: practice gaps with `id`, `severity`, `category`, `location`, `impact`, `recommendation`, `effort`, and `confidence`.
- `positivePatterns`: practices already working well.
- `recommendations`: pragmatic changes ordered by maintainability impact.

Balance theoretical best practices with the codebase context.
